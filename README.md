# 📊 SaaS/E-Commerce Cohort Retention & CLTV Analysis

## 🚀 Project Overview

This project analyzes customer retention and Customer Lifetime Value (CLTV) using the Online Retail II dataset.

The objective is to identify customer churn patterns, calculate lifetime value, and provide actionable business insights through Cohort Analysis and interactive dashboards.

---

## 🎯 Objectives

- Clean and preprocess transactional data
- Perform Cohort Analysis
- Calculate Customer Lifetime Value (CLTV)
- Analyze customer retention
- Build an interactive Power BI dashboard
- Generate business insights
